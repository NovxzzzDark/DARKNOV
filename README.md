# 🚀 DarkNOV

> ⚠️ **PERINGATAN: Untuk Tujuan Edukasi dan Pengujian Keamanan Saja**

Project ini merupakan contoh tool untuk mempelajari konsep **request API, CLI, Python, dan pengujian keamanan**.

Gunakan hanya pada sistem yang Anda miliki atau yang telah memberikan izin secara tegas.

---

## 📌 Fitur

| Fitur | Deskripsi |
|---|---|
| 🧪 API Simulator | Mensimulasikan request API secara lokal |
| 🎨 UI Menarik | Antarmuka terminal dengan tampilan yang rapi |
| 🔄 Single Round | Menjalankan satu siklus pengujian |
| 🖥️ Lintas Platform | Dapat digunakan pada lingkungan terminal yang mendukung Python |

---

## 📋 Persyaratan

- Python 3.7+
- pip
- Koneksi internet jika pengujian membutuhkan API yang memang Anda miliki
- Termux / Linux / Windows

---

## ⚙️ Instalasi

```bash
git clone https://github.com/danzzzzgc/DarkNOV
cd DarkNOV
